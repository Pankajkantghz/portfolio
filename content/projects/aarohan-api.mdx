# Aarohan

A full-stack publishing platform that allows readers to discover and discuss articles, authors to create and manage publications, and administrators to moderate content and manage users.

Aarohan is a **full-stack publishing platform** built using the **MERN stack**, providing a complete content management experience with secure authentication, article publishing, and user engagement.

The platform focuses on content management with role-based authorization, secure authentication, and scalable backend architecture. Aarohan also provides author and admin dashboards, article analytics, email verification, and interactive API documentation.

## GitHub Repository

[**Aarohan Source Code →**](https://github.com/Pankajkantghz/roadmapsh-projects-solutions/tree/master/backend-projects-js/6.%20Aarohan)

## Features

- **Authentication & Authorization**: Secure signup, login, email verification, password recovery, and JWT-based authentication with refresh tokens.
- **Article Management**: Create, update, delete, publish, search, and filter articles with slug-based URLs.
- **User Engagement**: Like, dislike, bookmark articles, and participate in discussions through comments and nested replies.
- **Author Dashboard**: Manage profiles, drafts, published articles, and article analytics.
- **Admin Dashboard**: Manage users, update roles, moderate content, and monitor platform analytics.
- **File Uploads**: Upload and manage article images using Cloudinary.
- **Security**: Password hashing, HTTP-only cookies, Helmet, rate limiting, and request validation.
- **API Documentation**: Interactive API testing and documentation using Swagger UI.

## Technologies

- **MongoDB**: Database for storing users, articles, comments, and application data.
- **Express.js**: Backend framework for building RESTful APIs.
- **React 19**: Frontend library for building interactive user interfaces.
- **Node.js**: Server-side JavaScript runtime.
- **Mongoose**: ODM for MongoDB schema modeling.
- **JWT Authentication**: Secure authentication using access and refresh tokens.
- **bcrypt**: Password hashing and account security.
- **Zod**: Request validation.
- **Cloudinary**: Cloud-based image storage.
- **Multer**: File upload handling.
- **Nodemailer**: Email verification and password recovery.
- **Swagger UI**: Interactive API documentation.
- **Vite**: Frontend development and build tooling.

## Getting Started

### Backend

```bash
cd backend
cp .env.example .env
npm install
npm run dev
```

### Frontend

```bash
cd frontend
cp .env.example .env
npm install
npm run dev
```

The application runs at:

```text
Frontend: http://localhost:5173
Backend:  http://localhost:5000
```

## API Documentation

Explore and test API endpoints using Swagger UI:

```text
http://localhost:5000/api-docs
```

## Build for Production

Frontend:

```bash
npm run build
```

Backend:

```bash
npm start
```

## Conclusion

Aarohan demonstrates how a scalable full-stack publishing platform can be built using the MERN stack. With secure authentication, content management, user engagement, administrative moderation, and analytics, the platform reflects practical real-world full-stack engineering practices.
